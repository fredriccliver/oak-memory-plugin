# OpenAI 0.1.6 업데이트 제출 준비

기존 공개 plugin ID와 MCP key `oak-memory`를 유지한다. Claude용 MCP 이름은 별도인
`oak-memory-cloud`를 유지하며 URL과 OAuth 범위는 바꾸지 않는다.

OpenAI 포털의 정확한 5개 양성·3개 음성 사례 제한에 맞춰 제출 사례를 구성했다.
기존 12개 양성·8개 음성 사례는 내부 검증 파일에 보존한다. 10개 스킬은 같은 소스다.
릴리스 설명은 준비본 0.1.5 문구에서 실제 제출 버전 0.1.6으로 수정했다.

기존 2026-10-09 영상은 이전 연결 시연이다. 이 파일을 최신 UI나 추가 스킬의 새 검증
영상으로 주장하지 않는다. 현재 심사용 접근, 실제 시연과 포털 검사 결과를 확인한 뒤
제출한다. 역사적 GitHub ZIP은 덮어쓰지 않고 새 제출 후보 파일명과 checksum을 남긴다.

## 제출 전 확인

- 오래된 2026-10-09 demo URL은 초안 manifest에서 제거했다. 최신 실제 호스트 시연을 포털 Review details에 추가한 뒤 제출한다. 개인 기억 캡처를 심사 영상으로 공개하거나 이전 영상이 새 UI를 증명한다고 주장하지 않는다.
- 내부 12개 양성·8개 음성 사례는 보존했지만 전체 수동 실행을 완료했다고 주장하지 않는다. 파괴적 사례는 심사용 저장소에서 명시적 범위와 복구 절차를 확인한 뒤 검증한다.
- 공식 포털은 Individual Approved 상태인데도 초안 업로드를 거부한다. 0.1.6 초안 생성·심사 제출은 아직 완료되지 않았다.
- 릴리스 설명은 공식 공개 0.1.2의 스킬 1개와 비교한 내용이다. 이미 준비된 GitHub 0.1.6 소스의 스킬 10개와 비교한 PR delta가 아니다.
