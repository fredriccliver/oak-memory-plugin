# 능동적 store 메모리 관리

2026-11-01 사용자 합의에 따라 기본 정책은 자동 관리를 허용한다. 모델은 답변 전과
작업 도중에 필요한 맥락을 능동적으로 회상하고, 새 사실·결정·교정을 발견하면
답변 종료를 기다리지 않고 저장·수정·연결·해제·삭제·병합한다. 허용 범위 안에서는
매번 승인을 다시 묻지 않는다. 실제 클라이언트의 도구 실행·권한 제어는 유지한다.

정책은 store마다 독립적이다. Cloud는 해당 Cloud store 정책만 사용하고 로컬 정책은
로컬 store에만 적용한다. 정책 변경은 명시적인 요청과 해당 store 권한을 따른다.
처음 설정하지 않은 로컬 store는 기본 정책을 사용한다. 잘못되거나 읽을 수 없는
기존 정책을 기본 허용으로 대체하지 않는다. 기존 사용자 제한 정책은 보존한다.

실제 노출된 도구와 입력 스키마를 확인한다. 버전 번호로 병합 도구 유무를 추정하지
않으며 확인 실패는 미확인으로 남긴다. 원자적 병합이 가능하면 이를 사용한다.
수동 병합으로 조용히 전환하지 않는다. 응답 유실 등 결과가 불확실하면 같은 store를
자동 재조회하고, 미반영이 확인된 허용 작업만 재시도한다. 미확인을 무변경으로
보고하지 않는다.

검색은 관련도 기반 recallMemory를 사용한다. 전체 점검은 listMemories의 snapshot
cursor를 따라 모든 페이지를 읽는다. 목록은 기본 20개·최대 100개이며 링크와 응답
크기도 제한한다. 일부 페이지만 보고 전체 점검이나 링크 부재를 주장하지 않는다.
연결 검증은 저장소 이름·역할·연결 상태만 확인하며 본문 조회를 기본으로 하지 않는다.
